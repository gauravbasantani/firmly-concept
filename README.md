# Firmly concept

How a store could get ready for AI shoppers: see what agents will be asked, preview the product inside an assistant and an article, then choose where to sell.

An unofficial concept by Gaurav Basantani (https://gauravbasantani.com), based only on public information. Not affiliated with firmly. The store, products and numbers are made up.

Live page: https://gauravbasantani.github.io/firmly-concept/
